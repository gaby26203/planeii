# Historial de planes de Lovable

Estos archivos venían en la carpeta `.lovable/` de la exportación. Son los planes que el
agente de Lovable escribió antes de cada cambio, entre julio y octubre de 2026.

Sirven como historial de intención: explican por qué se hizo cada cambio. No son
documentación vigente. Ante cualquier duda, manda el código y lo descrito en `docs/`.
